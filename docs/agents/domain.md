# Domain docs

This is a single-context repository.

- Read `CONTEXT.md` before exploring or changing domain behavior.
- Read relevant ADRs under `docs/adr/` before changing hard-to-reverse decisions.
- Use the canonical terms from `CONTEXT.md` in issue titles, tests, code, and documentation.
- Update `CONTEXT.md` when domain language changes.
- Record only hard-to-reverse, surprising trade-offs in ADRs.
